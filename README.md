# kaskad

Основа для ассистента, который работает лесенкой. Сначала отвечают свои правила и своя база вопросов и ответов, потом локальная энциклопедия, и только если они не знают — нейросеть. Нужна только стандартная библиотека Python 3.8+, других зависимостей нет. Ядро выросло из `runtime.py` проекта PyBot (Hugging Face).

```
вопрос → модули: правила, своя база, команды   → ответ + действие (уровень 3)
           ↓ подходящего ответа нет
         энциклопедия (SQLite FTS5)             → ответ (уровень 4)
           ↓ всё ещё нет
         заглушка «не знаю» → нейросеть         → ответ (уровень 1)
```

## Быстрый старт

```sh
python -m kaskad -v -p "включи свет на кухне"   # один ответ с подробностями
python -m kaskad                                # диалог в терминале: /reset, /exit
python -m kaskad.check checks.json              # контрольные вопросы
python -m unittest discover -s tests            # тесты
```

Команду `kaskad` можно поставить через `pip install .`. Папку с модулями она ищет в текущем каталоге или берёт из `--modules`.

## Модули

Модуль — это обычный файл `.py` в папке `modules/`. Файлы, имя которых начинается с `_`, не считаются модулями, их можно импортировать как вспомогательные.

```python
PRIORITY = 500   # 9000 и выше — экстренный блок, ниже 0 — запасные ответы
LEVEL = 3        # уровень для отчёта: 3 — ассистент, 4 — энциклопедия

def observe(text, memory): ...       # запомнить что-то, не отвечая (необязательно)

def respond(text, memory):           # ответить или вернуть None
    return {"reply": "Включаю свет.",
            "action": {"service": "light.turn_on", "area": "kitchen"},
            "confidence": 0.9}

def after(text, reply, memory): ...  # после выбора ответа (необязательно)
```

`respond` может вернуть и просто строку. Каждый модуль работает со своей копией памяти, а память выбранного модуля становится памятью разговора. Модуль с ошибкой пропускается. Модуль, который не уложился в отведённое время (по умолчанию 2 с), тоже пропускается, и, пока он не освободится, его не запускают снова. В памяти можно хранить только значения, которые сохраняются в JSON.

Примеры в `modules/`:
- `base` — своя база вопросов и ответов и команды для света на русском, немецком и английском, данные в `data/base.json`;
- `name` — запоминает имя (пример `observe` и памяти разговора);
- `encyclopedia` — поиск по SQLite FTS5;
- `floor` — отвечает «не знаю», когда больше никто не ответил.

## Как выбирается ответ

Правила в `kaskad/arbiter.py` проверяются по порядку:
1. экстренный блок (PRIORITY 9000 и выше) отвечает всегда, и его ответ никогда не передаётся нейросети;
2. настоящий ответ важнее ответа «не знаю»;
3. ответ, дословно повторяющий предыдущий, уступает другому ответу, но на один и тот же вопрос, заданный дважды, бот ответит одинаково;
4. дальше решают приоритет, затем уверенность, затем порядок модулей.

Свой арбитр подключается так: `Assistant(arbiter=моя_функция)`.

## «Не знаю» и нейросеть

`Assistant.ask()` ставит признак `unknown` в трёх случаях: никто не ответил, ответ помечен `"unknown": true` или уверенность ниже порога (по умолчанию 0,5). Тогда вопрос уходит нейросети:

```sh
export ANTHROPIC_API_KEY=...         # или KASKAD_ANTHROPIC_URL для своего прокси
python -m kaskad --llm anthropic     # модель: KASKAD_LLM_MODEL, по умолчанию claude-haiku-5-5
python -m kaskad --llm openai        # llama.cpp, Ollama, LM Studio: KASKAD_LLM_URL, KASKAD_LLM_MODEL
```

Перед отправкой `llm.redact()` закрывает в вопросе и истории e-mail, IBAN и телефоны. Даты, суммы, параграфы и номера дел остаются. Имена и адреса он не находит, их нужно псевдонимизировать до того, как вопрос попадёт к ассистенту.

## Действия и Home Assistant

```sh
export KASKAD_HA_URL=http://homeassistant.local:8123 KASKAD_HA_TOKEN=...
python -m kaskad --home-assistant
```

Действие `{"service": "light.turn_on", "area": "kitchen"}` превращается в запрос `POST /api/services/light/turn_on` с телом `{"area_id": "kitchen"}`. Названия зон в `data/base.json` должны совпадать с ID зон в Home Assistant.

## HTTP

```sh
python -m kaskad --serve 8765 --sessions sessions.sqlite
curl -s localhost:8765/ask -d '{"text": "включи свет на кухне", "session": "call-1"}'
```

Сервер слушает только 127.0.0.1 и не проверяет, кто к нему обращается. Память разговоров хранится в SQLite, отдельно для каждой сессии. Модули выполняются по одному запросу за раз, а нейросеть и действия — вне этой очереди.

## Контрольные вопросы

В `checks.json` записаны вопросы и ожидания: `module`, `contains`, `action`, `unknown`, `level`. Для проверки разговора из нескольких реплик используется `steps`.

```sh
python -m kaskad.check checks.json --record golden.json    # сохранить снимок ответов
python -m kaskad.check checks.json --compare golden.json   # что изменилось после правки
```

## Что проверено

22 теста и 18 контрольных вопросов проходят на Python 3.8, 3.11, 3.12 и 3.13. Обращения к нейросетям и к Home Assistant проверены на локальном подставном сервере. С настоящим API Anthropic и с живым Home Assistant код не проверялся.
